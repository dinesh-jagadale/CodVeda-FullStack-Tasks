# Task 1 – Environment Setup

This task focuses on setting up the complete development environment
required for the CodVeda Full Stack Development tasks.

A proper environment setup ensures consistency, productivity, and
smooth development across all upcoming tasks.

## Tools Covered
- Git and GitHub
- Node.js and npm
- Database setup
- Basic terminal / PowerShell commands

## Folder Overview
- `git-github-setup/` – Git installation and GitHub configuration
- `nodejs-setup/` – Node.js and npm installation
- `database-setup/` – Database installation and basic configuration
- `terminal-commands/` – Common terminal commands for development

Each folder contains a detailed README with step-by-step instructions.
